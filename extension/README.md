# 岁瞬网页书签浏览器扩展

基于现有星云主页实现，打包为 Chromium Manifest V3 扩展，可用于 Google Chrome、Microsoft Edge 及其他兼容 Chromium 的浏览器。安装后，新建标签页会显示书签主页；点击工具栏中的扩展图标可把当前网页标题和网址带入“添加书签”表单。

## 安装（开发者模式）

1. 解压发行包，保留整个 `extension` 文件夹。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”，并选中 `extension` 文件夹。
4. 新建标签页即可使用。可在浏览器扩展菜单中将“岁瞬网页书签”固定到工具栏，便于快速收藏当前网页。

本项目没有申请读取所有网站数据的权限。只有在你主动点击扩展图标时，`activeTab` 才用于读取当前标签页的标题和网址；书签和偏好保存在扩展自己的浏览器本地存储中。收藏仅支持普通 `http` / `https` 网页，浏览器内部页面（例如 `chrome://`）不能收藏。

书签站点图标沿用网站版的 Google S2 favicon 服务。加载图标时，浏览器会向 Google 请求对应的站点域名图标；书签正文与设置仍保存在本地。

## 从网站版迁移自定义数据

网站版与扩展版属于不同的浏览器来源，浏览器不会自动共享它们的本地数据。请先在网站版的“设置 → 数据变动记录”中选择“导出数据”，然后打开扩展版新标签页的“设置 → 数据变动记录 → 导入数据”，选择刚导出的 JSON 文件。

## 注意

Chrome 扩展无法替换无痕窗口的新标签页；扩展数据保存在当前浏览器配置中，不会自动跨设备同步。卸载扩展前如需保留自定义数据，请先导出 JSON。
